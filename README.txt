NEXSKILL WEBSITE — READY TO UPLOAD

FILES
- index.html: website content and page structure
- style.css: responsive design, colors, layout, animations
- script.js: mobile menu, reveal animations, current year

BEFORE UPLOADING
1. Confirm your GitHub repository is the one that publishes https://nexo99067-lab.github.io/Nexskill/ .
2. Open the repository and look for the main website files. If the site is published from the repository root, upload/replace these three files in the root (same level as the current index.html).
3. If your existing site uses a /docs folder or another publishing folder, upload the three files to that published folder instead.
4. Replace the current index.html, style.css and script.js if they already exist. Keep any unrelated files such as CNAME or workflow files.
5. Commit the changes (for example, commit message: “Refresh NexSkill website”).
6. Wait a minute or two, then open the live website and refresh. On mobile, if old content remains, try a private/incognito tab or clear site cache.

CUSTOMIZATION
- Change page text in index.html.
- Change colors and spacing near the top of style.css in :root.
- All external links open in a new tab where appropriate.
- Google Fonts requires an internet connection; system fallback fonts will be used if unavailable.
