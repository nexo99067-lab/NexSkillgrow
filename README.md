# NexSkill Official — 10-page HTML website

## Pages included
1. `index.html` — Home
2. `about.html` — About Us
3. `services.html` — Services
4. `courses.html` — Courses & Learning
5. `pricing.html` — Pricing
6. `portfolio.html` — Portfolio (sample concepts clearly labelled)
7. `blog.html` — Journal
8. `faq.html` — FAQ
9. `contact.html` — Contact
10. `privacy-policy.html` — Privacy Policy template

Shared assets: `assets/css/style.css` and `assets/js/main.js`.

## Preview on a phone/computer
1. Download and extract the ZIP file.
2. Open the extracted folder.
3. Open `index.html` in Chrome. Internet is required for Google Fonts; the rest of the layout is local.

## Upload to GitHub Pages
1. Open your repository: https://github.com/nexo99067-lab/NexSkillofficial
2. Keep a backup of your current files first.
3. Upload all 10 HTML files plus the complete `assets` folder into the repository root (the top level, not inside an extra nested folder).
4. Commit the changes.
5. In repository Settings → Pages, make sure Pages is deployed from the correct branch (usually `main`, folder `/ (root)`).
6. Wait for the deployment to finish, then open https://nexo99067-lab.github.io/NexSkillofficial/ .
